Path rules for Blink on macOS 14 and later.

- Rules can now be limited to a path. Add `/acme` to a `github.com` rule to send only `github.com/acme/…` to Arc · Work, while the rest of GitHub follows your other rules or shows the picker.
- A path covers itself and everything below it, one segment at a time: `/team` matches `/team/page` but not `/teams`. Case doesn't matter, so `/Team/page` matches too.
- Put path rules above a rule for the whole domain. The Rules tab warns when an earlier rule means a later one is never used.
- The rules list, the "Test a link" field and the warnings show path rules as `github.com/team`.

Existing settings carry over and are upgraded the first time Blink saves them. After that, Blink 1.2 can't read them: if you go back to 1.2, it leaves the file untouched and runs without your rules until you update again.
