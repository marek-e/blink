A redesigned picker for Blink on macOS 14 and later.

- The picker is more compact, with smaller rows and keycap shortcut hints.
- An action bar names the key for each action: Copy (⌘C), Cancel (esc) and "Open in <browser>" (↩), which always names the browser Return opens.
- On macOS 26, the picker uses Liquid Glass, with glass buttons and a prominent Open button. macOS 14 and 15 keep a material background.

Rules, settings and keyboard shortcuts work as in 1.0.0, and existing settings carry over.
