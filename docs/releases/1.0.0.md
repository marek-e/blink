First release of Blink, a browser picker and link router for macOS 14 and later.

- A picker next to the pointer for links opened from other apps. Choose with 1 to 9, the arrow keys and Return, or a click.
- Domain rules, with optional subdomains, that send links straight to one browser. The first match wins, and Settings warns about rules that can never apply.
- "Always open this domain here" from the picker.
- Clear recovery when a browser is missing or refuses a link. Links are never sent somewhere you didn't choose.
- Default-browser setup, launch at login, Open Link for trying Blink first, and local HTML files.
- No history, no network requests, no URLs in logs.

Tested on macOS 26.6 (Apple silicon, and the Intel build under Rosetta) and macOS 14 (virtual machine) with Arc 1.168, Dia 1.53, Chrome 155, Zen 1.17, Safari 26.6 and Brave 1.97.

To stop using Blink, choose another default browser in System Settings › Desktop & Dock, turn off Open Blink at login, and move Blink to the Trash.
