Browser profiles for Blink on macOS 14 and later.

- Browsers with several profiles get a › in the picker. Click it, or press →, to show their profiles and open the link in one. ← hides them again. Choosing the browser itself still opens the link the way it always did.
- Works with Arc (by space), Dia, Chrome, Brave, Edge, Vivaldi, Zen and Firefox. Safari has no way to choose a profile from outside, so it stays a single row.
- Rules and "Always open" can send a domain to one profile, such as `github.com` → Arc · Work.
- Settings › Browsers lets you hide profiles you never pick, and the Rules tab warns when a rule's profile is gone.
- If a profile disappears, Blink says so and lets you open the link without it. It never falls back on its own.
- The picker's buttons now highlight under the pointer, and Open keeps the same width as the selection moves.

The first time a link goes to an Arc space or a Dia profile, macOS asks whether Blink may control that browser. Blink needs this to pick the space or profile; everything else works without it.

Blink now reads each browser's profile list to show profile names. It keeps only the names and IDs, and never reads history, cookies or tabs.

Existing settings carry over and are upgraded the first time Blink saves them. After that, Blink 1.1 can't read them: if you go back to 1.1, it leaves the file untouched and runs without your rules until you update again.
